# Bootstrap Laboratory

A collection of web development practicals created using **HTML, CSS, JS,
and Bootstrap 5**. Each practical demonstrates selected Bootstrap
components, layout utilities, and responsive design features.

## About the Project

This repository contains individual practicals for learning and
practising Bootstrap. Each practical has its own file so its
source code and supporting files stay organized.

The project is hosted as a static website using **GitHub Pages**.

## Technologies Used

-   HTML5
-   CSS3
-   Bootstrap 5
-   Bootstrap Icons, where needed
-   JavaScript for dyanmic content loading and indexing

Bootstrap is loaded using its CDN, so most practicals do not require a
local Bootstrap installation.

## Run Locally with a Development Server

If you prefer to use a local server, open the project folder in your
code editor and start a simple static server. For example, with the
**Live Server** extension in Visual Studio Code:

1.  Open the repository folder in Visual Studio Code.
2.  Install the Live Server extension if needed.
3.  Right-click `index.html`.
4.  Select **Open with Live Server**.

Using a local server is helpful when testing JavaScript modules and
relative file paths.
